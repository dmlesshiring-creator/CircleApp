# 🔐 Login and Build - Do This Now!

## I need you to login first (I can't enter your password)

### Step 1: Login to Expo

Run this command:

```bash
npx eas-cli login
```

**You'll be asked:**

```
? Email or username: 
```

**Options:**

### Option A: If you have an Expo account
- Enter your Expo username or email
- Enter your password
- Press Enter

### Option B: If you DON'T have an Expo account yet

First register:
```bash
npx expo register
```

Fill in:
- Username: (choose one, e.g., "ananya-circles")
- Email: your-email@example.com  
- Password: (choose a strong password)

Then login:
```bash
npx eas-cli login
```
